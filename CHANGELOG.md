# Журнал изменений

## 1.0.3

- Строки лога разделены переводом строки (раньше слипались через служебный разделитель).

## 1.0.2

- Исправлено: запись не скачивалась («скачан пустой файл»). При `setOutputStream` тело в файл пишет `getResult()`, а не `query()`. Найдено на боевом портале на первом же звонке.
- Запись прикрепляется сразу: фоновая задача после ответа вместо ожидания cron (до минуты). Агент остался только для повторов после неудачи.
- Одно дело обрабатывает один процесс (блокировка `Connection::lock`).
- Строки лога с датой, уровнем и подробностями (форматтер Битрикса дописывает только плейсхолдеры из текста).
- Название «[SH] Мои звонки: запись файлом», партнёр «ИП Шевчик И.С.», сайт bx-shef.by, сортировка 1003 (после shef.options 1000, shef.uiclear 1001, shef.problems 1002), как у остальных модулей линейки. Ключи переводов вида `shef.fixmoizvonki_*`.

## 1.0.1

- Исправлено: лог модуля молчал, потому что `LoggerRegistry` по умолчанию считает логгер выключенным. Теперь реестр не спрашиваем.
- В лог пишется и успешная обработка дела со статусом (прикреплено или причина пропуска).

## 1.0.0

- Первая версия: запись разговора из «Мои звонки» скачивается и прикрепляется к звонку и делу.
