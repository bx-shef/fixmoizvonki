# shef.fixmoizvonki

Модуль для коробочного Битрикс24. Приложение «Мои звонки» регистрирует звонок через REST без
записи, а ссылку на запись вписывает в описание дела. Модуль скачивает запись и прикрепляет её
к звонку и делу так же, как это делает обычная телефония: файл в Диске, плеер в таймлайне,
запись в детализации звонков.

## Как работает

1. События CRM `OnActivityAdd` и `OnActivityUpdate`: если в описании дела есть `moizvonki.ru`,
   ставится разовый агент (сеть в сохранении дела не трогаем).
2. Агент находит звонок по `ORIGIN_ID` дела, проверяет ссылку (только `https://*.moizvonki.ru/calls/recordings/`),
   скачивает файл и кладёт в Диск в папку записей Voximplant.
3. Прописывает `CALL_RECORD_ID`/`CALL_WEBDAV_ID` в статистике звонка и `STORAGE_ELEMENT_IDS` в деле,
   убирает из описания плеер и ссылку, оставляет длительность.
4. Не получилось (звонок ещё не завершён, сервис недоступен): повтор раз в минуту, до 10 раз.

Штатный `Voximplant\Rest\Helper::attachRecordWithUrl` не используется: он принимает только
mp3, flac, wav, а «Мои звонки» отдают m4a.

Старые дела не обрабатываются, только созданные или обновлённые после установки.

## Установка

Папку модуля положить в `bitrix/modules/shef.fixmoizvonki/`, затем Настройки → Настройки продукта →
Модули → «Мои звонки: запись разговора файлом» → Установить. Установщик проверяет PHP ≥ 8.2, UTF-8
и наличие модулей `crm`, `voximplant`, `disk`. Модуль автономный: `shef.options` и `shef.problems` не нужны.

Журнал: `shef.fixmoizvonki.log` в каталоге `sh_log` на уровень выше корня сайта. Свой логгер можно
описать в `/bitrix/.settings.php`, секция `loggers`, id `shef.fixmoizvonki.main`. Агентам нужен
рабочий планировщик (cron или хиты).

## Тесты

```bash
php tests/run.php
```

Проверяют разбор ссылки, обработчик, установщик, переводы и форматирование. Скачивание и
прикрепление проверяются на портале.
